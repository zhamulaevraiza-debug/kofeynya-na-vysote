# Кофейня на высоте — Glass

Прототип мобильного приложения кофейни: клиентская часть и панель бариста в одном
файле, без сборки и зависимостей — чистый HTML/CSS/JS. Оформление перенесено из
макета Claude Design «Кофейня на высоте - Glass»: матовое стекло, тёплое золото,
Cormorant Garamond в заголовках и фотография интерьера как подложка.

## Запуск

**С сервером** (нужен для `index.html` — фотографии лежат рядом в `assets`):

```bash
python -m http.server 8731
```

Затем откройте http://localhost:8731

**Без сервера** — откройте «Кофейня на высоте — автономная.html» двойным кликом.
Все фотографии вшиты внутрь, файл работает откуда угодно и пересылается целиком.
Обычный `index.html` при открытии прямо с диска покажет пустые места вместо фото:
относительные пути в режиме `file://` не работают — для этого и сделана копия.

Пересобрать автономную копию после правок `index.html`:

```bash
python build-standalone.py
```

## Вход

- **Клиент** — «Пропустить» (гостевой режим) или регистрация: она даёт +500 баллов.
- **Бариста** — ссылка «Вход для персонала» внизу экрана входа. Выберите
  сотрудника и введите его PIN (демо-коды: Ахмад — `2412`, Муса — `7391`).
  После 5 неверных попыток ввод блокируется на 30 секунд.

## Что внутри

**Клиент** — стартовый экран, вход и регистрация, главная с промо и галереей
«Атмосфера гор», меню по категориям, карточка товара с объёмом и добавками,
корзина со скидкой 10%, бронь столика, заказы с трекером статусов, бонусы,
избранное, история заказов, адреса, карты оплаты, светлая и тёмная темы.

**Панель бариста** — главная со сводкой смены, реестр заказов
(«Новые → В работе → Готовы → Выполненные»), брони, меню и остатки, смены,
клиенты, финансы, уведомления, профиль.

Обе половины работают на общем состоянии: заказ клиента сразу виден бариста, а
смена статуса возвращается клиенту уведомлением и начислением баллов.

## Как устроено

Полная перерисовка на каждое изменение состояния — разметка собирается строками,
затем новое дерево морфится в старое, поэтому не сбрасывается прокрутка, не
теряется фокус в поле и не перезапускаются анимации.

- `S` — всё состояние; `setS` меняет временное, `set` пишет ещё и в хранилище
- обработчики кладутся в массив, в разметку уходит их номер (`data-c`)
- палитра задана переменными на корне, тема меняется подстановкой строки
- стекло навешивается одним правилом на всё, что красится через `var(--card)`

Состояние хранится в localStorage браузера под ключом `knv2`; сервер ничего не
сохраняет. Подробный разбор приёмов — в справочнике проекта.

## Границы прототипа

Сервера нет — обе половины работают с одним localStorage, поэтому заказ с телефона
не увидит бариста за стойкой. Вход не защищён: пароль никуда не отправляется, вход
в панель открыт без кода. Из карты сохраняются только платёжная система и последние
четыре цифры (`{ brand, last4 }`) — номер, срок и код не записываются никуда.
Фотографии напитков грузятся с фотостока, фотографии заведения лежат локально.
